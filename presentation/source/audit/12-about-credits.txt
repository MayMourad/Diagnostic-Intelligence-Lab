A student research prototype.

Built by three high-school students (Grades 11 and 12) to ask a simple question seriously: when a diagnosis is read from an image, how accurately — and how would we know?

Provisional title

“Diagnostic Intelligence Lab” is a temporary project title. The platform is deliberately not named after one specialty so it can grow beyond retinal screening; the first research task is referable diabetic retinopathy.

How to rename it

The name, school and student list live in one file, js/brand.js. The mark is a generic reticle-and-scale symbol with no text, so a new name needs no layout changes.

Method in one paragraph

Sixteen synthetic fundus illustrations are generated deterministically from authored lesion lists. Each reference label is derived from its lesion list under the ICDR scale and re-checked by an automated test. Visitors read cases blind, lock an interpretation, then see the reference. Accuracy statistics are exact and unit-tested; they can be computed on held-out predictions the user supplies, and otherwise only an explicitly labelled simulator is shown.

The 3D eye

An original lightweight WebGL model written for this project (no third-party scene or library), with a static SVG fallback. Anatomy shown: cornea, iris, pupil, lens, vitreous body, sclera, choroid, retina, macula/fovea, optic disc and optic nerve; the optic disc sits nasal to the macula. It is an orientation aid, not clinical evidence, and not to scale.
